# ProofHound 完整依赖锁（含传递依赖）—— 可复现安装入口
#
# 用法（干净环境）：
#   python3.12 -m venv .venv
#   .venv/bin/pip install -r requirements.txt
#   .venv/bin/pip install -e . --no-deps --no-build-isolation
#
# 直接依赖的**声明**仍以 pyproject.toml 为准（本文件只钉版本、不改语义）；
# tests/test_release_hygiene.py 断言两者不漂移。升级是显式动作：改 pyproject →
# 重装 → 跑全量测试 → 重新生成本文件。
#
# 生成方式（在已通过全量测试的 venv 中）：
#   .venv/bin/pip freeze --exclude-editable | sort -f
#
# 历史沿革：M5a 起本文件先只锁 API 层三项（fastapi/uvicorn/httpx），M8b 加入
# playwright；M13 起改为**完整锁**——原先的四项 pin 与 pyproject 的 `>=` 实际
# 解析结果已经漂移（uvicorn 0.52.1→0.54.0、playwright 1.62.0→1.63.0，均仍满足
# pyproject），漂移由守护测试钉死，故不再是"写死的四个版本"。
#
# 注：Chromium 二进制不在 pip 内，verify-xss 需另跑
#     `.venv/bin/python -m playwright install chromium`（缺失时该验证 fail-closed）。
